## 安装与下载

### 支持什么电脑？Mac 可以用吗？

当前提供 **Windows 11 x64** 安装版，适用于常见的 Intel / AMD 64 位电脑。macOS 暂不支持；Windows 10 与 Windows ARM 设备尚未完成适配验证。

可以在 Windows“设置 → 系统 → 系统信息”的“系统类型”中查看处理器架构。

### 应该下载哪个文件？

打开[最新版本](https://github.com/lanziyi36-eng/luo-xiaohei-desktop/releases/latest)，在 Assets 中选择 **`Xiaohei-Setup-0.2.37-win-x64.exe`**。双击安装即可，不需要编译、安装开发工具或额外下载模型。

`.sha256` 是校验文件。GitHub 自动显示的 Source code ZIP / tar.gz 是本发布仓库的说明文档，不是应用安装包，也不包含应用源码。

### 下载需要 GitHub 账号吗？

这个发布仓库公开可访问，查看说明和下载安装包无需登录。提交问题或建议需要登录 GitHub。

### 为什么 Windows 提示未知发布者或保护了电脑？

当前安装器尚未代码签名，Windows 可能显示发布者提示。请确认文件来自本仓库的 Release，并核对文件名称与 SHA-256；若系统提示具体威胁，请保留提示内容并反馈，不要关闭安全防护。

可在 PowerShell 中运行下面的命令，把文件路径替换为下载位置，再与 Release 附带的 `.sha256` 文件比较：

```powershell
Get-FileHash -LiteralPath '安装包的完整路径.exe' -Algorithm SHA256
```

## 使用中的问题

### 小黑不见了，怎么找回来？

查看任务栏右侧托盘区及其小箭头内的小黑图标，使用快捷菜单显示桌宠；也可以重新打开桌面“启动罗小黑”。菜单中的“回到右下角”可重置摆放位置。

### 为什么待办没有提醒？

确认小黑正在运行、“提醒设置”中已开启待办提醒，并且未处于全屏或演示模式。只设日期、没有具体时间的待办不会触发到点提醒；新建或重新安排在此刻及未来 5 分钟内的待办也不提醒。

### 为什么课表图片识别不准确？

模糊、字号太小或复杂合并表格都可能影响识别。尽量使用清晰、完整的截图，保留星期与节次表头，并在核对页修改结果后再导入。OCR 不会自动替你确认所有内容。

### 课表提示无法读取怎么办？

程序会尝试读取有效备份，无法恢复时保留原文件。不要通过删除数据目录来重置；先备份，修复后使用“重新读取”。需要帮助时可以反馈错误提示，无需公开整份个人课表。

### 图标或快捷方式异常怎么办？

重新运行当前安装器修复，然后重新打开小黑。0.2.37 已修复 Windows 11 任务栏仍显示默认图标的问题。

## 备份与更新

### 我的数据存在哪里？如何换电脑？

记录保存在当前 Windows 用户目录下的 `.xiaohei-windows` 文件夹。按 `Win + R`，输入 `%USERPROFILE%\.xiaohei-windows` 即可打开。

备份时，先关闭桌宠并退出托盘程序，再完整复制这个文件夹。换电脑后，先安装并运行一次小黑，再关闭桌宠和托盘；备份新电脑已有的数据后，将原文件夹复制到新电脑当前用户目录下，再重新启动。

导出笔记适合阅读与分享；完整迁移请备份整个数据文件夹。

### 如何更新或卸载？

更新时，从本仓库下载新版安装器并运行，个人记录会保留；当前没有自动更新功能。可关注仓库的 Releases 获取版本通知。

卸载时，在 Windows“设置 → 应用 → 已安装的应用”中找到“罗小黑”。卸载会移除程序，保留个人记录，便于重装后继续使用。
