# 数据说明

[返回首页](../README.md) · [备份方法](FAQ.md#备份与更新)

小黑无需注册账号。随手记、待办、课程、作息和提醒设置保存在当前电脑的用户目录中，课表图片识别在本机执行，不上传到识别服务器。

应用不提供云端同步，也不收集使用情况遥测。完整安装后，日常使用与图片识别可以离线进行。

个人数据位于 `%USERPROFILE%\.xiaohei-windows`，与程序安装目录分开。升级和卸载会保留记录；备份、迁移与删除个人记录由你控制。

导出文件和备份可能包含个人内容，请自行选择保存与分享对象。本仓库的问题反馈公开可见，反馈前请遮住截图中的个人信息，不要上传完整数据目录。

下载页面和问题反馈由 GitHub 提供，相关网页访问与账号服务适用 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
